# WebPracticas_TriciaEstilista
A simple website I had to create for my DAM 1 internship

💈 Hair Salon Website

Designed in a minimalist style 🎨 for a hair salon that wanted a clean, simple way to share key information with its clients.

✨ Features
📍 Location — easy-to-find address and map integration
🕒 Hours — clear display of opening and closing times
💇 Services — a curated list of services offered, with pricing
📱 Responsive Design — looks great on mobile, tablet, and desktop
⚡ Fast & Lightweight — no unnecessary clutter, just what the user needs
🎯 Purpose

The goal was to create a simple, elegant, and functional website that reflects the salon's aesthetic while making it effortless for visitors to find the information they need — without distractions.

🛠️ Built With
HTML5 / CSS3 🌐
